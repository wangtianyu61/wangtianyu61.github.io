## Adding a paper

Copy the block in [templates/paper-entry.html](templates/paper-entry.html) into
the appropriate `<ul class="paper-list">` in `publications.html` (the complete
Research list). For selected papers, also add the same block to the relevant
section in `topics.html` (By Topic). Keep an entry's metadata consistent across
both pages. Replace the title, paper URL, authors, and venue or revision status.
Omit the `paper-venue` paragraph when no venue or revision status is listed.

The format is: linked title and bracketed resource links; authors; venue/status;
optional preliminary-version notes; optional awards. Delete optional elements
that do not apply. Add links such as `[Code]`, `[Poster]`, `[Website]`, or
`[Python package]` inside `paper-links`. Preserve `<u>T. Wang</u>` and use
`<sup>*</sup>` or `<sup>+</sup>` for the contribution markers defined on the page.

Add one `<li>` per recognition inside `paper-awards`. The shared rules in
`jemdoc.css` render these as smaller muted-red notes with a left border and
indent, following the [reference award style](https://hamsabastani.github.io/research.html).
Paper spacing is automatic; no spacer spans or extra `<br />` tags are needed.
